## pytest
**1.** assert用来断言，自己设置断言语句，然后程序根据运算的结果与断言的结果进行对比，相当于程序帮你判断正确性
**2.** @pytest.fixture：当 pytest 执行测试函数时，如果发现测试函数的参数名与某个 @pytest.fixture 定义的函数名相同，就会自动执行对应的 fixture 函数，并将其返回值传给测试函数
**3.** tmp_path 也是 fixture，但是pytest 内置的 fixture。作用是创建一个临时目录，并返回对应的 Path 对象。用法例子：ignored_directory = tmp_path / ".git"
**4.** @pytest.mark.parametrize： @pytest.mark.parametrize("参数名", [数据列表]) 的作用，就是让 pytest 依次把列表中的数据传给测试函数的同名参数，每组数据独立执行一次测试("参数名", [数据列表]) 的作用，就是让 pytest 依次把列表中的数据传给测试函数的同名参数，每组数据独立执行一次测试

## pytest
**1.** assert用来断言，自己设置断言语句，然后程序根据运算的结果与断言的结果进行对比，相当于程序帮你判断正确性

**2.** @pytest.fixture：当 pytest 执行测试函数时，如果发现测试函数的参数名与某个 @pytest.fixture 定义的函数名相同，就会自动执行对应的 fixture 函数，并将其返回值传给测试函数

**3.** tmp_path 也是 fixture，但是pytest 内置的 fixture。作用是创建一个临时目录，并返回对应的 Path 对象。用法例子：ignored_directory = tmp_path / ".git"

**4.** @pytest.mark.parametrize： @pytest.mark.parametrize("参数名", [数据列表]) 的作用，就是让 pytest 依次把列表中的数据传给测试函数的同名参数，每组数据独立执行一次测试("参数名", [数据列表]) 的作用，就是让 pytest 依次把列表中的数据传给测试函数的同名参数，每组数据独立执行一次测试

## Path
**1.** 
```python
relative_path = file_path.relative_to(
    repository_root
)
```
这个的意思是file_path相对于repository_root的绝对路径，不是直接转换为绝对路径

**2.** path.name只获取最后一级名称，例如
```python
path = Path("D:/project/src/main.py")
```
中的path.name是main.py

**3.** Path.expanduser() 只负责展开路径开头表示用户目录的部分
例如用户传入：
```python
repository_path = "~/projects/demo"
```
执行：
```python
Path(repository_path).expanduser()
```
会得到类似：
```python
C:\Users\Dell\projects\demo
```

**4.** Windows 通常使用反斜杠 \，而 Linux 和 macOS 使用正斜杠 /。如果项目需要跨平台运行，最好统一路径格式。这就是 as_posix() 的作用

** 深拷贝
1. 深拷贝用于复制一个对象及其内部嵌套对象，使副本尽量不与原对象共享可变数据。
```python
original = {
    "agent": {
        "timeout": 300,
    }
}
# 浅拷贝
shallow = copy(original)
# 深拷贝
deep = deepcopy(original)
```
修改了浅拷贝的内层字典后：
```python
shallow["agent"]["timeout"] = 600

print(original["agent"]["timeout"])
# 600

print(shallow["agent"]["timeout"])
# 600
```
修改深拷贝的内层字典后：
```python
deep["agent"]["timeout"] = 900

print(original["agent"]["timeout"])
# 600

print(deep["agent"]["timeout"])
# 900
```
